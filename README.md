# 游戏内压缩算法与数据压缩系统

## 项目描述

游戏内压缩算法与数据压缩系统的bug修复项目。核心模块 `utils/compression.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- LZ77压缩完全没做资源都是未压缩的
- Huffman压缩完全没做不能根据频率生成最优编码
- 解压完全没做压缩了的资源不能解压
- 字典完全没做重复的数据不压缩
- 压缩级别完全没做不能在速度和压缩率之间权衡

## 运行测试

```bash
python -m pytest tests/test_compression.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
